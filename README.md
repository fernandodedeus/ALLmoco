# ALLmoço 🍽️

ALLmoço é uma aplicação web desenvolvida em ASP.NET Core Razor Pages com foco em acompanhamento alimentar diário.

O projeto foi criado inicialmente como uma solução pessoal para ajudar no acompanhamento de refeições e construção de hábitos alimentares consistentes.

É importante ressaltar que esse projeto foi inteiramente desenvolvido (v0.2) com auxílio e acompanhamento de uma AI com foco no aprendizado e técnica prática em um
projeto real e que resolvesse um problema.

---

# 🚀 Tecnologias

- ASP.NET Core Razor Pages
- C#
- Entity Framework Core
- Postgres
- Bootstrap
- CSS
- Git/GitHub
- Railway

---

# ✨ Funcionalidades

- Registro de refeições
- Registro de refeições não realizadas
- Campo de descrição/motivo
- Histórico de refeições
- Sistema de streak
- Mensagens motivacionais dinâmicas
- Exclusão individual de refeições
- Limpeza completa do histórico
- Validação anti-duplicação
- Dark Mode responsivo
- Login e Cadastro
- Tela multiusuário

---

# 📸 Objetivo

O ALLmoço foi desenvolvido para transformar acompanhamento alimentar em algo simples, leve e acolhedor.
